# 2026-11-11

## 快速链接改为青柠式白色方卡 + 每行 5 列（1.9.0-rc1）

- 图标方卡：`.quicklink-icon` 由 38px 圆形改为 88×88、圆角 18 的方卡；图标 22 → 46px。底色新变量 `--quicklink-card-bg`（浅色 #ffffff / 深色 #2b2b2b），极淡阴影 `--quicklink-card-shadow`，两者均已在 `mdBuildVarText` 中映射为 `surfaceContainerLow`。
- 尺寸分档改为 CSS 变量 `--quicklink-card-size / --quicklink-item-width / --quicklink-glyph-size / --quicklink-gap`，由 `script.js` 的 `QUICKLINK_METRICS`（480/760 断点：64/76/88）写入，`index.html` 媒体查询保留同值默认值供首帧使用。`early.js` 必须同步这套分档。
- 每行项数：`QUICKLINK_COLUMNS = 5`，窗台（`data-quicklink-position="bottom"`）保留 `QUICKLINK_COLUMNS_BOTTOM = 9`。非底部位置不再按项数截断（`maxItems = Infinity`），单行/多行设置项保留但行为一致。
- 容器宽度恒为 perRow 列，一行未满时由 `justify-content: center` 居中；`#inner` 网格行改为 `1fr auto 48px 52px 18px 18px auto 2fr`，搜索框中心落在视口约 36%–37%。
- 首帧占位高度改为 calc 表达式（卡片边长 + 40px 名称区），`.quicklink-title` 固定 24px 高，避免增强可见性的内边距改变项高。
- 图标源 `api.xinac.net/icon` 实测返回 128×128 PNG，放大到 46px 无需更换。
- 版本号升至 `1.9.0-rc1`（manifest 1.9.0 + version_name）。
- 悬停反馈只作用于图标方卡：`.quicklink-item:hover` 不再设底色，改为 `.quicklink-item:hover .quicklink-icon` 使用 `--quicklink-card-bg-hover`（浅色 #f0f0f0 / 深色 #383838，MD 映射 `surfaceContainerHigh`）；`transition` 也移到 `.quicklink-icon`。原先 `.quicklink-icon` 被"浅色无背景"规则用 `--plain-floating-bg` 覆盖，已把该选择器收窄为只作用于 `#fakebox`，否则悬停色被更高特异性覆盖。
- 教训：本机浏览器截图接口对高 DPI 页面返回超过 10MiB 的图，验证改为「临时 iframe 探针 + 请求 query 打到 http.server 访问日志」读取 getComputedStyle，比截图可靠。
